RetroCastX · Colorlight i5 + CH347F

ゲートウェアをブラウザから書き込む

基板の USB-C を PC に挿し、Chrome / Edge でこのページを開いて書き込みます。追加の ソフトは要りません(Windows のみ下記の準備が必要)。書き込み経路はオンボードの CH347F → ポゴピン → Colorlight i5 の JTAG で、ECP5 の SPI フラッシュを直接書き換えます。

このブラウザは WebUSB に対応していません。Chrome または Edge で開いてください (Safari / Firefox は非対応です)。

1. 基板に接続

「FPGA を再起動」は LSC_REFRESH を発行してフラッシュから読み直させる。 書き込みが途中で止まって FPGA が起動していないときの復帰に使う。

3. 書き込む

書き込み中は FPGA が停止するため、映像・音声のキャプチャは一時的に止まります。 完了すると自動で新しいゲートウェアが起動します。途中で USB を抜かないでください。

  Windows: CH347F の JTAG インターフェース(interface 4)に WinUSB ドライバを
  当てる必要があります。Zadig を「Options → List All Devices」で起動し、
  UART+SPI+I2C+JTAG (Interface 4) を選んで WinUSB をインストールしてください。
  WCH 純正の CH347 ドライバが入っていると競合します。macOS / Linux / ChromeOS / Android では
  追加作業は不要です。

  デバイスが選択ダイアログに出ない: USB-C ケーブルが充電専用(データ線なし)でないか
  確認してください。

  書き込みが途中で失敗した: FPGA は起動しませんが JTAG は生きています。
  そのままもう一度書き込めば復旧します。
