コンデンサ 84 個すべてを「どの部品のどのピンの直近に置くか」で引ける表。designator と回路上の役割は default.kicad_pcb の atopile_address プロパティとネットリストから機械的に対応付けてあり、ピン番号は main.ato の部品定義に一致する。ネットリスト上は同じ電源ネットでも、電源ピン群ごとに1個ずつ割り当ててあるので、まとめて置くと片方が無防備になる。

優先度の意味

  • 最優先 ループ面積が効く。2mm 以内・ビアを挟まない。ここを妥協すると実測で症状が出た箇所
  • 直近 対象ピンの直近（5mm 以内目安）。パッド → コンデンサ → GND の経路を短く、GND ビアはコンデンサ直下に
  • 近傍でよい レール上のバルクや終端。10mm 程度離れても実害は小さい
座標は hardware/adc-frontend/layouts/default/default.kicad_pcb の配置（2026-08-11 時点）。部品を動かすと変わる。
