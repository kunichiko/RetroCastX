# RetroCastX 小亀基板(コンソール入力基板) v1.0

家庭用ゲーム機向けの入力端子を引き受けて、**0.5mmピッチ20芯FFC(10cm)**で
メイン基板(`hardware/adc-frontend`)へ渡すサブ基板。外形はメイン基板と同じ
**10cm × 10cm**、取付穴は M3 ×5(メイン基板の H1-H5 と同じ位置にしてスペーサで重ねられる)。

```
  S端子(ミニDIN4) ─┬─ESD─ 75Ω ─ 100n ─┬(bias 1.65V)─┐
                   │                                  ├ SPDT ch1 ─ FFC 1 ─→ GIN_1 / SOGIN_1
  コンポジット(黄) ─┴─ESD─ 75Ω ─ 100n ─┘              │   (ESD: D2=CVBS/音声L/R
                                                       (選択 = FFC 13 = FPGA GPIO)
  S端子C ───────────ESD─ 75Ω ─ 100n ──┬──────────────┤    D3=S端子Y/C・Pr/Pb)
  コンポーネントPr(赤)─ESD─ 75Ω ─100n ─┘              └ SPDT ch2 ─ FFC 3 ─→ RIN_1

  コンポーネントPb(青)─ESD────────────────────────────── FFC 5 ─→ BIN_1(終端はメイン基板側)
  音声L(灰/黒) ─ESD─ 10k ─────────────────────────────  FFC 7 ─→ PCM1808 #3
  音声R(赤)   ─ESD─ 10k ─────────────────────────────  FFC 9 ─→ PCM1808 #3
  シリアルLED ×2 ←── FFC 11(データ)/ 16(+5V, ダイオードで4.2V)
```

Y/C分離も復調もこの基板ではやらない。メイン基板の TVP7002 で 8fsc サンプリング
して、Viewer(PC側)でデコードする(`docs/composite-video-plan.md`)。

## FFC ピン配置(メイン基板と共通)

メイン基板(J15)側の番号で書く。**小亀基板(J1)は逆順(n ↔ 17-n)**。

| pin | 信号 | pin | 信号 |
|---|---|---|---|
| 1 | 音声L | 11 | LED_DATA |
| 2 | GND | 12 | GND |
| 3 | 音声R | 13 | GPIO2(予備) |
| 4 | GND | 14 | GND |
| 5 | Pb(スイッチを通らない) | 15 | GPIO1(スイッチ選択) |
| 6 | GND | 16 | GND |
| 7 | C / Pr(スイッチ出口) | 17 | +3.3V |
| 8 | GND | 18 | +3.3V |
| 9 | Y / CVBS(スイッチ出口) | 19 | +5V |
| 10 | GND | 20 | +5V |

**信号は全部が両隣にGNDを持ち、電源は2本ずつ**(2026-09-22 に16芯から20芯へ)。
16芯のときは制御3本(LED_DATA/GPIO2/GPIO1)が並んでいて、800kHzのLEDデータが
隣のGPIOと並走していた。電源を2本にしたのは往復抵抗を半分にするため。

★**ケーブルの向き(type A / type D)は発注前に確認すること。** FFCは両端の接点が
同じ面か反対面かで「n番 ↔ n番」と「n番 ↔ 17-n番」が入れ替わる。**このネットリストは
ストレート(n ↔ n)前提**。2枚の基板の向きを決めたら紙に描いて種別を選び、
**通電前にテスターで pin1↔pin1 を当たること**。1ピンずれると +5V が GPIO に当たる。

## 入力の切り替え(TS5A23159 / 1本の選択線)

真理値表(データシート SCDS201H Table 2: IN=L → NC-COM が ON)。

| GPIO1 | FFC 1 (→GIN_1/SOGIN_1) | FFC 3 (→RIN_1) | FFC 5 (→BIN_1) | 使える入力 |
|---|---|---|---|---|
| **L(既定・10kプルダウン)** | CVBS(黄) | Pr(赤) | Pb(青) | コンポジット / **YPbPrコンポーネント** |
| H | S端子 Y | S端子 C | (Pb) | S端子 |

- **既定をコンポジットにした理由**: ゲートウェアがこのGPIOを駆動しない状態でも
  「黄色いケーブルを挿しただけで映る」ようにするため。S端子とコンポーネントは
  Viewer で明示的に選ぶ操作を伴うので、そのときに H へ駆動される。
- **同期(SOGIN_1)はスイッチの出口から分岐している**ので、映像と同期が必ず
  一緒に切り替わる。人が触る物理スイッチだと「設定はコンポジットなのにスイッチは
  S端子側」という食い違いを作れてしまう(`docs/TODO.md` 10-5)。
- break-before-make なので、切り替えの瞬間に2つのソースが繋がることはない。

## 75Ω終端と中点バイアス(この基板の設計の要点)

**終端はこの基板のジャック側に置く**。メイン基板の `VideoInputChannel` が持つ
75Ω(`r_term`)は、**この基板で終端するチャンネル(Y/C)では実装しない**。
両方に入れると合計37.5Ωになり振幅が半分になる。

終端の直後に 100nF で直流を切り、10kΩ で 1.65V(VCC/2)へ持ち上げてから
スイッチに入れている。理由は**スイッチの信号範囲が GND〜VCC** だから:

```
出力にコンデンサが入っている機種(AC結合)を 75Ω でGNDへ終端すると、
波形の平均が0Vになるので同期先端が負に潜る
    暗い絵(平均0.35V)  同期先端 ≈ -0.35V
    白い絵(平均0.85V)  同期先端 ≈ -0.85V   ← 絶対最大 -0.5V を超える
潜る量が絵の明るさで動くので、スイッチの保護ダイオードが同期先端だけを食う。
同期先端は SOG スライサが見ている場所なので、明るい絵のときだけ同期が乱れる。
```

v0.9.0(2x4ヘッダ)は同じ 75Ω→100nF の並びだったが、終端ノードに能動素子が
無かったので問題にならなかった。スイッチを入れる v1.0 では効いてくる。

Pb だけはスイッチを通らないので直流結合のまま渡し、終端もメイン基板側
(`ch_b1` の 75Ω)に任せている。

## 部品(LCSC)

| 部品 | 型番 | LCSC | 備考 |
|---|---|---|---|
| ミニDIN4(S端子) | **マル信 MJ-373/4B** | — (手実装) | 千石/マルツ/モモハラ。3=Y / 4=C / 1,2=GND / スロット3本=シェル |
| RCA ×5 | **RCA-105**(色違い) | — (手実装) | AliExpress等。黄/白/赤/黒/青が同寸法で揃う。**2端子・両方とも軸線上** |
| FFCコネクタ | HDGC 0.5K-1.5-**20**PWB | C2919559 | 下接点・フリップロック・右アングル |
| アナログスイッチ | TI TS5A23159DGSR | C42751 | 2ch SPDT, Ron 1Ω, break-before-make |
| ESD ×2 | ROHM EMZT6.8ET2R | C510333 | メイン基板と同じ(5パッド版フットプリント) |
| シリアルLED ×2 | XINGLIGHT XL-2020RGBC | C5349955 | MSL3(JLCの焼成不要) |

ミニDIN4はLCSCに無いので**フットプリントをメーカー図面から自作**した
(`parts/_mech/MJ373_4B.kicad_mod`。φ1.2×4 + スロット2.8×0.8×3、原点=嵌合面)。
メイン基板のミニDIN8(マル信 MJ-373/8B)と同じハウジング/ランド枠。

RCAは**フットプリントをメーカー図面から自作**した(`parts/_mech/RCA105.kicad_mod`)。
ランドは **2端子だけで、両方ともコネクタの軸線上**:

    pad1  スロット 2.30 × 1.50  @ 嵌合面から 4.80  → シェル(GND)
    pad2  スロット 1.00 × 2.30  @ 嵌合面から 8.30  → 中心導体(信号)

★**極性は現物で導通確認すること。** 2端子しかないので取り違えると映像をGNDへ短絡する
(「筒の外側 ↔ pad1」「中心の穴 ↔ pad2」を当てれば10秒)。
★**同じ RCA-105 でも出品元で寸法が違うことがある**ので、4.80/8.30 とスロット寸法を実測してから発注する。
★外形と並べ方(枠10.0mm・筒がφ8.3で9.3mm張り出す・ピッチは12.5mm)は
`docs/layout-guidelines.md` の1章にまとめた。

レイアウトの指示は `docs/layout-guidelines.md`(外形・コネクタ形状・配置・配線ルール)。

## ビルド

```
ato build                               # ネットリスト/PCB/BOM を生成
```

部品の取り込み(atopileの部品APIが落ちているときのオフライン手順)は
メイン基板と同じ `tools/ingest_parts.py`:

```
~/.local/share/uv/tools/atopile/bin/python tools/ingest_parts.py C2939342 ...
```

★**ESDアレイ(EMZT6.8ET2R)を取り込み直したら `tools/fix_esd_land.py` を必ず走らせる**
(取り込み時のフットプリントはリードの無い裸パッドを含む6パッド版で、パッド幅も
0.28mmしかない)。いまリポジトリに入っているのはメイン基板で修正した5パッド版。

## 発注前チェックリスト

1. **FFCの向き**: type A(同面接点)+ 対向配置の前提で小亀側を逆順(n↔17-n)にしてある。
   紙に描いて確認し、通電前に pin1↔pin1 を導通確認
2. **ミニDIN4のピン**: 現物で「3番がプラグの輝度ピン」を導通確認(図面の
   PCB穴図のパッド番号=ミニDIN4の標準ピン番号として扱っている)
3. **RCA-105 の極性とランド**: pad1=GND / pad2=信号 を導通確認し、4.80/8.30 を実測
4. **メイン基板側の 75Ω**: `ch_y` / `ch_c` の `r_term` を実装しない指定になっているか
   (v1.0 の main.ato では `VideoInputChannelNoTerm` を使う。未対応なら手で外す)
5. 取付穴の位置をメイン基板と合わせる(M3 ×4)
