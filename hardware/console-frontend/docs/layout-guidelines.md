# RetroCastX 小亀基板(コンソール入力基板) レイアウト指示書

回路は `main.ato`(atopile)。ネットリスト/PCBは `ato build` が生成し、**配置は保持される**。
メイン基板側の指示書は `../../adc-frontend/docs/layout-guidelines.md`。

---

## 0. 基板全体

| 項目 | 値 | 理由 |
|---|---|---|
| 外形 | **100 × 100 mm** | メイン基板と同じ。JLCの最安枠に収まる |
| 層数 | **2層で足りる** | 信号は数本・数十mmしかない。裏面をベタGNDにすれば映像(〜30MHz)には十分。メイン基板(4層)と違ってDDRもGbEも無い |
| 板厚 | 1.6mm | **コネクタのスロット寸法が t=1.6 前提**(図面の "T:1.6")。変えてはいけない |
| 取付穴 | **M3 ×5(H1-H5)** | メイン基板と同じ個数・同じ座標にする。基板左上を原点にすると H1 (5,5) / H2 (5,95) / H3 (95,95) / H4 (95,41) / H5 (70,5)。四隅の3つ + 辺の途中2つという配置(メイン基板は残る1隅をコネクタが占めている)。**片方が4個だとスペーサが1本浮く** |
| 裏面 | ベタGND(切らない) | 映像の帰り電流の経路。スリットを入れると同期にリンギングが乗る |

★金属スペーサ・金属筐体だと論理GNDが筐体に落ちる点はメイン基板と同じ注意
(あちらは MagJack のシャーシGND島を 4.7nF/2kV で分離している)。

## 1. ★RCAジャック(RCA-105)の形状 — ここが配置を決める

メーカー図面(出品ページの画像に入っている)から読んだ寸法。**2端子しかなく、
両方ともコネクタの軸線上**にある。

```
        側面(軸を含む断面)                          嵌合面から見た正面
   ←─ 9.30 ─→|←──── 10.00±0.20 ────→
   ┌──────────┐ 嵌合面                       ┌────────────┐  ┬
  ( φ8.30    │  ★ = 基板外形をここに合わせる  │  ╭──────╮  │  │ 5.00
   └──────────┘  │                           │  │ φ3.50│  │  ┴ ← 筒の軸
        筒は基板の外へ  │  ┌─ pad1 (4.80)      │  ╰──────╯  │
        9.30 張り出す  │  │  ┌─ pad2 (8.30)    └──┬──┬────┘  13.00
                      ▼  ▼  ▼                    │足│        │
   ────────────────────┼──┼──┼─── 基板 (t=1.6)    └──┘        ┴
                       └──┴──┘ 足 3.70          ←── 10.00 ──→
                                                 筒の軸は基板面から 8.00
```

| 寸法 | 値 |
|---|---|
| フランジ(基板に載る枠) | **10.00 幅 × 13.00 高** |
| 本体の奥行 | 嵌合面から後ろへ **10.00 ±0.20** |
| 筒 | **φ8.30 ±0.10**、嵌合面から**前へ 9.30 張り出す** |
| 筒(軸)の高さ | 基板面から **8.00**(フランジ上端から 5.00 下) |
| 足 | 3.70 長(t=1.6 なら裏へ 2.1 出る) |
| ランド | pad1 = スロット **2.30 × 1.50** @ 嵌合面から 4.80 / pad2 = スロット **1.00 × 2.30** @ 8.30。**どちらも軸線上(y=0)** |
| 極性 | **pad1 = シェル(GND)、pad2 = 中心導体(信号)** ← ★現物で導通確認すること |

- 図面は**裏面視(Printed-bottom view)**だが、2パッドとも軸線上なので鏡像にしても同じ。
  そのまま表面のフットプリント(`parts/_mech/RCA105.kicad_mod`)に使っている。
- フットプリントの**原点 = 嵌合面 × 軸**。silk が基板に載る 10×10 の枠、F.Fab に
  筒の張り出し(x = −9.3〜0)を描いてあるので、**基板外形を x=0 に合わせる**だけでよい。

### 並べる間隔は 12〜13mm

枠は 10.0mm なので物理的には 10.5mm ピッチで並ぶが、**RCAプラグの握りは φ10〜14mm ある**。
10.5mm ピッチだと隣同士に同時に挿せない。AV機器のパネルも 12.5mm 前後なので、
**12.5mm を基準**にする(5個で 62.5mm)。

### ミニDIN4(MJ-373/4B)の形状

| 寸法 | 値 |
|---|---|
| フランジ | 14.0 幅 × 13.0 高 |
| 本体の奥行 | 嵌合面から後ろへ 12.7 |
| ランド | φ1.2 ×4(x = 8.5 / 11.0、y = ±3.25)+ シェル用スロット 2.8×0.8 ×3((4.7, 0) 縦、(5.5, ±6.85) 横) |
| 原点 | 嵌合面(x=0) × 中心線(y=0)。**RCAと同じ流儀**なので基板外形を x=0 に合わせる |

## 2. コネクタの並び

100mm の辺に 6 個並べる。合計幅は 14.0(ミニDIN4)+ 12.5 × 5 = 76.5mm なので余裕がある。

```
   ┌──────────────────────────────────────────────────────────┐ ← この辺を前面にする
   │  S端子    赤      青      黄      白      赤              │
   │ (DIN4)   (Pr)    (Pb)  (CVBS)  (音声L) (音声R)           │
   │  14.0    12.5    12.5   12.5    12.5    12.5             │
   │          └─ コンポーネント(Y=CVBS兼用/Pr/Pb) ─┘           │
   │                          └─ コンポジット+音声(黄白赤) ─┘   │
   └──────────────────────────────────────────────────────────┘
```

- **コンポーネント3本(Pr / Pb / Y=CVBS兼用)が隣り合う**ようにしてある。YPbPr で
  使うときに3本のケーブルが1か所にまとまる。
- 同時に **CVBS(黄)→ 音声L(白)→ 音声R(赤)** が並ぶので、黄白赤の3本AVケーブルも
  そのまま挿せる。
- **赤が2個(Pr と 音声R)あるが両端に分かれる**ので混同しにくい。それでも
  シルクには `Pr` / `AUDIO R` と必ず書く。
- 音声L に白が無い色ロットを買った場合は灰か黒にして、シルクで `L` と明示する。
- S端子を端に置くのは、ミニDIN4のフランジが 14mm で一番大きいため。

## 3. 配置の大方針(信号の流れ)

```
ジャック ── ESD ── 75Ω終端 ── 100nF ── (中点バイアス 10k) ── スイッチ ── FFC
 前面の辺        ↑ここまで各ジャックの直近          ↑基板中央       ↑FFCの辺
```

| 部品 | 置き場所 |
|---|---|
| **D2**(ESDアレイ) | **CVBS / 音声L / 音声R** = 右の3ジャックの直近(1chあまる) |
| **D3**(ESDアレイ) | **S端子C / S端子Y / Pr / Pb**(io1..io4 の順)= 左の3ジャックの直近。Y と C を入れ替えてミニDIN4 との交差を消してある |
| R2/R4/R6/R8(75Ω) | **ジャックの足のすぐ横**(終端は送り出しから見て一番奥に置きたいが、この基板では「スイッチより手前」が必須条件) |
| C2/C3/C5/C6(100nF 結合) | 75Ωの直後 |
| R1/R3/R5/R7(10k バイアス) | 各チャンネルの結合コンデンサの直後。**vbias ノードは C1(10µF)の近くへ集める** |
| U1(TS5A23159) | **FFCコネクタ(J1)の近く**。スイッチの出口から FFC までを短くする |
| R9(選択線プルダウン) | U1 の IN1/IN2 のそば |
| R10-R13(10k) | 音声2本とバイアス分圧。音声の 10k はジャックのそば |
| LED1/LED2 + D1 + C4 | **ジャックの近く**(光って見える位置)。D1 と C4 は LED の電源のそば |
| J1(FFC) | メイン基板を向ける辺。**1番ピンにシルクを打つ** |

## 4. 配線ルール

- **映像線(Y/C/CVBS/Pr/Pb)は裏面ベタGNDの上を通す。** 線幅 0.3mm、長さは 40mm 以内を
  目安に。8fsc(28.6MHz)でも 40mm は電気的に短い(往復0.4ns)ので特性インピーダンスは
  問わないが、**ベタの切れ目の上は通さない**。
- **LED_DATA(800kHz、立ち上がりが速い)を映像線と長く並走させない。** 間にGNDを挟むか、
  基板の別の辺を回す。メイン基板側に直列220Ω(源端整合)が入っている。
- **vbias(1.65V)は AC的にはGND扱い。** C1(10µF)をバイアス分圧の直近に置き、
  そこから各チャンネルの 10k へ配る。ここが長いと 4 チャンネル間の漏れが増える
  (10k → vbias → 10k の経路。C1 が効いていれば -70dB 級)。
- **シェル/GNDは太く。** RCAの pad1 とミニDIN4のスロット3本は、裏面ベタへビアで直接。
  ジャックのシェルは静電気の入口なので、細いネックを作らない。
- 3.3V/5V は FFC から来るだけなので細くてよい(LEDの 5V だけ 0.4mm 以上)。

## 4.5 ★フットプリントを差し替えたときの手順(踏んだ罠)

`main.ato` で部品の品番/サイズを変えると、`ato build` は**既存のフットプリントを
その場で置き換える**(配置・回転・配線・ゾーンはそのまま残る。これは助かる)。
ただし2つ落とし穴がある。**2026-09-21 に 0402 → 0603 の差し替えで両方踏んだ。**

1. **1回目の build では新しいパッドにネットが付かない。**
   差し替えとネット割当が同じパスで走るため、置き換わったパッドが `(net …)` を
   持たない状態で書き出される。症状は **pcbnew でラッツネストが出ない** / DRCの
   「未配線」が減る(ネットの無いパッドは接続判定の対象外)/ パッドが他ネットの
   配線に乗っていると `shorting_items` が出る。
   → **`ato build` をもう一度走らせる**。それだけで直る。確認方法:

          grep -c '(pad ' layouts/default/default.kicad_pcb   # パッド総数
          # ネット未割当パッドが0であること(下のワンライナーで数える)
          python3 -c "import re,pathlib;s=pathlib.Path('layouts/default/default.kicad_pcb').read_text();\
          print(sum(1 for m in re.finditer(r'\(pad \"[^\"]+\"[\s\S]{0,700}?(?=\(pad \"|\Z)',s) \
          if not re.search(r'\(net \d+ \"', m.group(0))))"

2. **ゾーンの塗りが古いまま残る。** パッドが大きくなった分だけGNDベタが食い込み、
   `clearance`(ゾーン 0.5mm に対して現状 0.03mm)と `solder_mask_bridge` が大量に出る。
   → **pcbnew で `B`(全ゾーンを塗り直す)**。ヘッドレスなら:

          /Applications/KiCad/KiCad.app/Contents/Frameworks/Python.framework/Versions/3.9/bin/python3 -c \
          "import pcbnew;b=pcbnew.LoadBoard('layouts/default/default.kicad_pcb');\
           pcbnew.ZONE_FILLER(b).Fill(b.Zones());pcbnew.SaveBoard('layouts/default/default.kicad_pcb',b)"

   0402→0603 ではこれで銅箔系の違反(clearance / shorting / mask bridge)が**全部ゼロ**に
   なった。残るのは `silk_overlap`(シルクの重なり、31→67件)だけで、これは大きい部品に
   した代償なので、配置の微調整とシルクの整理で潰す。

★**PCBファイルを消して作り直すのは禁止。** 配置が飛ぶ(2026-09-21 に実際に飛ばした)。
フットプリントのプロパティ(LCSC番号等)が古いまま残るときだけ、
`(property "atopile_address" "<名前>")` で該当ブロックを特定して**その1個だけ**消す。

3. ★**ブロックを1個消す場合も、その部品の配置は失われる。**(2026-09-22、メイン基板の
   J13 で踏んだ。(86.8, 107.2) に置いてあったものが (86.3, 107.5) にずれた。)
   **消す前に `(at x y [rot])` を控えて、build のあとに書き戻すこと。**
   pcbnew を開ける状況なら **Tools → Update Footprints from Library** の方が安全
   (位置・回転を保ったままライブラリの内容だけ更新される)。
4. ★**`lock_designators.py` は最後の `ato build` の後に走らせる。** ロックの後に
   build すると PCB 側のデジグネータだけが欠番に戻ることがある(同じく J13 で踏んだ。
   ロックは「変更なし」と言うのに PCB は J3 になっていた)。**最後に PCB を直接
   grep して確かめる**のが確実。
戻せる保険は `build/builds/default/backups/default.<時刻>.kicad_pcb` と
`build/builds/default/default.pcbnew-0.<時刻>.kicad_pcb`(毎ビルドの直前状態)。

## 5. 製造(JLCPCB)

- **2層・t=1.6・HASL** で足りる。部品はSMDが 20 個ちょっと(0402中心)で、
  **コネクタ類(RCA×5、ミニDIN4)は手実装**なので PCBA から外れる(`has_part_removed`)。
- **スロット穴(PTH)が4種類ある**。ガーバー/ドリルを出したあと、
  **スロットが route コマンドとして出ているか**を確認すること(円穴に化けていると
  コネクタが入らない)。

  | 部品 | スロット |
  |---|---|
  | RCA-105 ×5 | 2.30×1.50 と 1.00×2.30(各ジャック2個) |
  | MJ-373/4B | 0.8×2.8 ×1、2.8×0.8 ×2 |

  JLCのPTHスロット最小幅は 0.5mm なので、いずれも余裕がある。
- フィデューシャル(FID1-3)は非対称に3個。0.5mmピッチ(FFCコネクタとVSSOP-10)が
  あるので入れておく。

## 6. 発注前チェックリスト

`../README.md` の末尾にも同じものがある。**レイアウトを終えた時点で全部当たること。**

1. **FFCの向き**: type A(同面接点)で2枚を同一平面・開口部を向かい合わせにする前提で、
   小亀側のピン割当を**逆順(n ↔ 17-n)**にしてある。紙に描いて確認し、
   **通電前にテスターで pin1↔pin1 の導通**を見る
2. **RCA-105 の極性**: pad1=シェル(GND)/pad2=中心導体(信号)を現物で導通確認。
   2端子しかないので取り違えると**映像をGNDへ短絡する**
3. **RCA-105 のランド**: 買った現物で 4.80/8.30 とスロット寸法を実測
   (同じ「RCA-105」でも出品元で微妙に違うことがある)
4. **ミニDIN4**: 3番がプラグの輝度ピンに導通するか
5. **メイン基板側の 75Ω**: `ch_y`/`ch_c` が `VideoInputChannelNoTerm`(終端なし)に
   なっているか。両方で終端すると振幅が半分になる
6. 取付穴が**5個**で、メイン基板と同じ座標(H1 5,5 / H2 5,95 / H3 95,95 / H4 95,41 /
   H5 70,5)になっているか(重ねられるか)
